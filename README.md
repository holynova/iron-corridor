# 铁甲回廊 · Iron Corridor

**坦克大战 × Roguelike** — 一款在浏览器里直接运行的俯视角坦克对战 Roguelike。

程序化生成的回廊、逐层升级的三选一强化、每 5 层出现的 BOSS、以及用废料兑换的永久强化，
构成一局约 15–30 分钟、一命通关的短流程挑战。

```bash
npm install
npm run dev        # http://localhost:5199
npm run build      # 类型检查 + 产物打包到 dist/
npm run preview    # 预览生产构建
```

浏览器需要支持 WebGL 与 Web Audio（Chrome / Edge / Firefox / Safari 16+ 均可）。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 驾驶战车 | `W` `A` `S` `D` / 方向键 |
| 炮塔瞄准 | 鼠标（炮塔独立于车体转向） |
| 开火（可按住连射） | 鼠标左键 / `空格` |
| 冲刺（带短暂无敌） | `Shift` / `F` |
| 切换武器 | 鼠标滚轮 / `Q` `E` |
| 暂停 | `ESC` / `P` |

### 单局流程

1. **逐层深入** —— 每层是一张程序化生成的回廊，包含 3 波敌对装甲。
2. **清场强化** —— 每波结束回复少量生命并投放补给；升级与通关都会给出**三选一强化**（共 25 种，可叠加）。
3. **BOSS** —— 每 5 层出现「钢铁霸主」，血量与弹幕随深度递增；10 层与 20 层后换装强化。
4. **一命通关** —— 坦克被击毁即本局结束，共 30 层通关即胜利。没有读档。
5. **永久成长** —— 击杀掉落废料，在主菜单「军械库」兑换 6 项永久强化，数据保存在浏览器本地。

### 战场规则

- **木制掩体**（褐色货箱 / 沙袋）可被炮弹摧毁，**金属掩体**（灰蓝货箱）不可摧毁。
- **油污火区**会持续灼烧其中的一切单位，敌我通吃。
- 掉落物包含废料、修复包、护盾、原子弹，以及精英单位必掉的**临时武器箱**（机枪 / 霰弹 / 激光 / 电磁炮 / 迫击炮）。
- 炮塔带有小范围**辅助瞄准**：准星附近的敌人会被轻微吸附，否则高速横向移动的坦克几乎无法命中。

### 敌人

| 单位 | 行为 |
| --- | --- |
| 侦察兵 | 高速绕圈，保持距离 |
| 炮手 | 三连发，边打边撤 |
| 重装 | 高血量高伤害，直线压上 |
| 狙击手 | 远距离高伤单发，会主动拉开距离 |
| 冲锋者 | 不计后果的贴脸冲锋 |
| 蜂群 | 数量多、极脆，路径带摆动 |
| 炮台 | 固定炮位，四连发扇形弹幕 |
| 钢铁霸主 | BOSS，血条、追踪弹幕、大范围碾压 |

精英单位（金色光环、2.1 倍血量）每波间歇出现，掉落武器箱。

## 技术实现

- **引擎**：Phaser 3.90 + TypeScript（`strict`）+ Vite
- **美术**：Kenney「Top-down Tanks Redux」「Top-down Tanks」素材包，CC0 1.0
- **字体**：Kenney Font Package，CC0 1.0
- **音效**：Kenney Digital Audio / RPG Audio，CC0 1.0
- **音乐**：无音频素材，使用 Web Audio 实时合成的芯片音乐（方波主旋律 + 三角波贝斯 + 程序化鼓组），强度随战斗状态动态变化
- **无外部运行时依赖**：只依赖 Phaser；贴图、粒子、UI 全部在 `BootScene` 里程序化生成

### 几个值得一提的实现点

- **地图是烘焙出来的**：整张 1920×1440 的地面（瓦片、污渍、岩石、房间光晕、掩体投影）
  在进入该层时一次性画进离屏 canvas 并上传为单张贴图。否则数百个静态精灵会显著拖垮帧率。
- **敌人会真正寻路**：以玩家位置为源的 BFS 距离场每 0.22 秒重建一次，直线通畅时朝玩家直冲，
  被掩体挡住时沿距离场梯度绕行。没有这一层，坦克会集体卡在掩体后面发呆。
- **转向用速度向量而不是角度**：径向与切向分量先合成向量再求角度。早期版本直接对角度做加法，
  导致环绕行为把坦克一路带离玩家。
- **弹道辅助瞄准**：准星 0.13 弧度锥内若有目标，出膛角会向其偏转半程。飞行时间 + 横向机动
  会让纯手动瞄准几乎打不中高速单位。
- **受伤有全局无敌帧**：接触伤害与炮弹共用一个冷却，否则一群冲锋兵可以在半秒内连锁致死。
